# Finance Shared Folder Not Opening - Easy Steps

Version Header: v 1.0 | 07/08/2026 | Status: Initial Draft

## What this means

If your Finance shared folder is not opening, do not worry. Your files are safe and are not deleted. This is usually a connection problem that can be fixed with a quick sign-out and sign-in.

## Try these steps

1. Save any work you currently have open.
2. Close all open programs.
3. Sign out of Windows.
4. Wait 60 seconds.
5. Sign in to Windows again.
6. Select the folder icon on your taskbar to open your files.
7. Open the Finance shared folder again.
8. If it still does not open, wait 5 minutes.
9. Try opening the Finance shared folder one more time.

## If the folder still does not open

Contact the IT Help Desk if the Finance shared folder still does not open after you complete the steps above.

When you send a help request, include these details:

- Your full name
- Your work login name
- Your computer name (for example, DESKTOP-XXXXX)
- Your team (Finance)
- The time the problem started
- What message you see on screen (exact words if possible)
- Whether sign out/sign in was completed
- Whether waiting 5 minutes and trying again was completed
- Whether any coworkers near you have the same problem

This information helps the IT Help Desk fix the problem faster.
